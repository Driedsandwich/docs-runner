A working Python quickstart

Run each command in order, in /work. No credentials or downloads are needed.

1. Write a tiny application

printf 'print("Hello from Docs Runner")\n' > hello.py

Expected file: hello.py

2. Run the application

python3 hello.py

Requires step 1. Expected stdout: Hello from Docs Runner

3. Inspect Python

python3 --version

This step has no documented expected result.
